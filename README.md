# IONLAB REFINERY (주식회사 이온랩 위탁 정련 플랫폼)

특허출원 제10-2026-0182129호 기반 소규모 다품목 고순도 금 추출 위탁 정련(임가공) 서비스 웹 애플리케이션입니다.

## 주요 기능
- **실시간 KRX 금 시세 연동**: KRX Open API 기반 1g당 금 시세 실시간 조회 및 시뮬레이터 자동 반영
- **투트랙(Two-Track) 비용 & 기대수익 시뮬레이터**: 금도금 모재(1일 공정) / IC·BGA 칩 모재(2일 공정) 작업비 및 고수율 하이브리드 정산 실시간 계산
- **온라인 위탁 추출 신청서**:
  - Cloudflare R2 (`ionlab-refinery-img`) 모재 실물 사진 업로드 (최대 3장)
  - Cloudflare D1 (`ionlab-refinery`) 신청 내역 및 견적 데이터 영구 저장
  - Resend 이메일 API 기반 실시간 접수 알림 발송
  - 접수 완료 영수증 모달 (클립보드 복사, PNG 이미지 요약서 다운로드, TXT 요약서 다운로드)
